# Student Management System

# Project Objective
The objective of this project is to create a simple website for managing student records. Users can add, search, and delete student information.

# Project Overview
I made this project using HTML, CSS, and JavaScript. Student details like name, age, course, and marks are displayed on the website. The website is also responsive and works on mobile and desktop.

# Technologies Used
HTML, CSS, JavaScript, Git, GitHub, and GitHub Pages.

# Main Features
-> Add students
-> Delete students
-> Search students
-> Form validation
-> Responsive design

# JavaScript Concepts Used
I used functions, arrays, objects, loops, conditions, array methods, DOM manipulation, and events.

# Challenges
The main challenge was connecting JavaScript with the HTML and updating the student records dynamically. Making the website responsive was also a challenge.

# Solutions
I used DOM manipulation and JavaScript functions to update the records. I used CSS media queries to make the website responsive.
